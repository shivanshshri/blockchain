<h1>Simple Blockchain with Proof of Work<h1>

<h2>Overview</h2>

<p>This project is a simplified implementation of a blockchain in Python to understand how Bitcoin’s Proof-of-Work consensus mechanism functions.<p>

<h3>It demonstrates:</h3>

        Block structure
        
        SHA-256 hashing
        
        Nonce-based mining
        
        Adjustable difficulty
        
        Block linking via previous hash
        
        Chain validation

<h2>How Proof of Work Works</h2>

<p>Each block must produce a SHA-256 hash that satisfies a difficulty condition (leading zeros).
The nonce is incremented until a valid hash is found.</p>

This simulates the core mining concept used in Bitcoin.



<h3>What I Learned</h3>

How cryptographic hashing ensures immutability

How nonce-based mining enforces computational work

How blocks are linked to form a secure chain

How validation detects tampering
